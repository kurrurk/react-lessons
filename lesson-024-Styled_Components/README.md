# Урок 64: Знакомство со Styled Components

💅 В данном разделе рассмотрена библиотека **Styled Components**, позволяющая создавать стилизованные React-компоненты с использованием CSS непосредственно в JavaScript.

## Изученные темы

- Что такое Styled Components.
- Создание компонентов со встроенными стилями.
- Использование шаблонных строк (`template literals`).
- Передача свойств (`props`) для динамического изменения стилей.
- Инкапсуляция стилей внутри компонентов.

## Пример

Создание стилизованного компонента:

```jsx id="ytj1gn"
import styled from "styled-components";

const Button = styled.button`
  padding: 1rem;
  border-radius: 8px;
  background: #42b883;
  color: white;
`;
```

Использование:

```jsx id="dlj5bh"
<Button>Click me</Button>
```

## Преимущества

- Стили привязаны к конкретному компоненту.
- Отсутствие конфликтов имен CSS-классов.
- Возможность динамически изменять стили через `props`.
- Улучшенная поддерживаемость и переиспользуемость компонентов.
- Не требуется отдельный CSS-файл для каждого компонента.

## Практика

- Выполнена установка и настройка Styled Components.
- Созданы первые стилизованные компоненты.
- Рассмотрено применение CSS внутри JavaScript.
- Освоено создание компонентов с инкапсулированными стилями.
