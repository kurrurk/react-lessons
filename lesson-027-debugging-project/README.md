# Уроки 71 - 75: Debugging - React Error Messages, Warnings, DevTools & Breakpoints

🐞 В данном разделе рассмотрены основные инструменты поиска и устранения ошибок в React-приложениях с использованием сообщений об ошибках, предупреждений, **React DevTools** и точек останова (Breakpoints).

## Изученные темы

- Чтение сообщений об ошибках React.
- Анализ предупреждений (Warnings).
- Использование React DevTools.
- Работа с Breakpoints в инструментах разработчика.
- Пошаговая отладка JavaScript-кода.
- Поиск причин возникновения ошибок.

## Сообщения об ошибках

React предоставляет подробные сообщения об ошибках, которые помогают определить:

- место возникновения ошибки;
- компонент, в котором произошла проблема;
- возможную причину ошибки.

Правильный анализ текста ошибки значительно ускоряет процесс поиска неисправностей.

## Предупреждения (Warnings)

Помимо ошибок, React выводит предупреждения, которые не останавливают работу приложения, но помогают обнаружить потенциальные проблемы, например:

- отсутствие уникального `key` в списках;
- использование устаревших API;
- некорректную передачу `props`;
- возможные ошибки в логике компонентов.

## React DevTools

React DevTools — это расширение для браузера, которое позволяет исследовать дерево компонентов React в режиме реального времени.

С его помощью можно:

- просматривать структуру компонентов;
- анализировать значения `props` и `state`;
- отслеживать изменения компонентов при повторном рендере;
- упрощать поиск ошибок в приложении.

## Работа с Breakpoints

Breakpoints позволяют приостановить выполнение программы в выбранной строке кода и проанализировать текущее состояние приложения.

Во время отладки можно:

- просматривать значения переменных;
- выполнять код пошагово;
- отслеживать порядок вызова функций;
- анализировать стек вызовов.
