# Уроки 67 - 68: CSS Модули

В этом уроке мы познакомились с использованием **CSS Modules** в React, а также научились динамически изменять стили компонентов в зависимости от их состояния.

## Что изучили

- Что такое CSS Modules и зачем они нужны.
- Как подключать CSS-модули к React-компонентам.
- Чем CSS Modules отличаются от обычного CSS.
- Как динамически добавлять и изменять CSS-классы.
- Как комбинировать несколько CSS-классов в одном компоненте.

## Что сделали

В ходе урока были созданы отдельные CSS-модули для компонентов и подключены с помощью импорта.

```jsx
import styles from "./Button.module.css";
```

Для применения стилей использовалось обращение к объекту `styles`:

```jsx
<button className={styles.button}>Click me</button>
```

Также были рассмотрены способы динамического изменения классов в зависимости от состояния компонента.

Например:

```jsx
<button
  className={`${styles.button} ${isValid ? styles.valid : styles.invalid}`}
>
  Submit
</button>
```

В результате внешний вид элемента автоматически изменяется при изменении состояния приложения.

## Преимущества CSS Modules

- Локальная область видимости классов.
- Отсутствие конфликтов имен между компонентами.
- Удобная организация стилей.
- Простое использование динамических классов.
- Хорошая масштабируемость проекта.

## Итог

Использование CSS Modules позволяет изолировать стили каждого компонента и избежать конфликтов между ними. В сочетании с динамическими классами это дает возможность легко изменять внешний вид компонентов в зависимости от их состояния, сохраняя код чистым и удобным для поддержки.
