# Урок 26 - Композиция (props.children)

В этом уроке было рассмотрено понятие **_композиции_** в React — подхода, при котором сложные пользовательские интерфейсы создаются путем объединения более простых и независимых компонентов. Композиция позволяет повторно использовать код, упрощает поддержку приложения и делает структуру интерфейса более гибкой и понятной.

Также в уроке был приведён практический пример использования композиции и рассмотрены преимущества **_компонентов-оболочек (Wrapper Components)_**. Такие компоненты помогают переиспользовать общую логику и оформление, уменьшают дублирование кода и позволяют создавать более универсальные и легко поддерживаемые интерфейсы.
