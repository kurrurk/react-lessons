# Урок 65: Styled Components и Динамические Props

🎨 В данном разделе рассмотрено использование **динамических свойств (props)** в библиотеке **Styled Components** для изменения внешнего вида компонентов в зависимости от их состояния или переданных данных.

## Изученные темы

- Использование `props` внутри Styled Components.
- Динамическое изменение CSS-свойств.
- Условное применение стилей.
- Повторное использование компонентов с разным оформлением.
- Разделение логики и представления.

## Пример

Создание компонента с динамическими стилями:

```jsx id="dbt77s"
import styled from "styled-components";

const Button = styled.button`
  background: ${(props) => (props.primary ? "#42b883" : "#35495e")};

  color: white;
`;
```

Использование:

```jsx id="y1t9zd"
<Button primary>Save</Button>
<Button>Cancel</Button>
```

В зависимости от значения `primary` компонент автоматически изменит цвет фона.

## Преимущества

- Простое создание нескольких вариантов одного компонента.
- Отсутствие необходимости вручную переключать CSS-классы.
- Логика оформления находится рядом с компонентом.
- Улучшенная читаемость и переиспользуемость кода.
