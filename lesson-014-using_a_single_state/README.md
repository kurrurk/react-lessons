# Уроки 39 и 40 - Использование Одного Состояния

- **Урок 39:** Использование одного состояния.
- **Урок 40:** Обновление состояния, зависящего от предыдущего состояния.

> ℹ️ **Примечание**
>
> В уроке рассмотрены два способа обновления объекта состояния:
>
> ```js
> setUserInput({
>   ...userInput,
>   description: event.target.value,
> });
> ```
>
> и
>
> ```js
> setUserInput((previousState) => {
>   return {
>     ...previousState,
>     description: event.target.value,
>   };
> });
> ```
>
> Второй подход (функциональное обновление состояния) рекомендуется использовать в случаях, когда новое значение зависит от предыдущего состояния, поскольку он гарантирует работу с актуальной версией state.
